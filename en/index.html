Flagship features

Five pillars that earn the name

The core features that make Orch term not just a terminal but a multi-agent workstation. Each card links to a detailed guide.

Multi-agent workstation

Terminal, editor, and browser in split panes of one window. Arrange three kinds of tabs freely.

→ One-window anatomy

Agent orchestration

The AI you're talking to spins up other AIs as workers and collaborates over multiple turns. A commander/worker model.

→ Commander guide MCP :9611 · open/send/close

AI gateway

External programs call AI through a local API (OpenAI-compatible). Machine-to-machine automation.

→ Gateway HTTP :9610 · /run · Bearer

SSH · SFTP

Native russh in-tab connections. Remote explorer, SFTP editing, vault, and port-forwarding tunnels.

→ SSH guide

CDP browser mirror

Mirror an agent's browsing (chrome-devtools-mcp) into an in-app panel in real time.

→ Mirror guide
