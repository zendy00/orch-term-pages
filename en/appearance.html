More · System

Appearance · Fonts · Shortcuts

Tune the app's look and feel to your taste. Pick a coding font with a live preview, adjust window opacity, and reassign keyboard shortcuts — all from the hamburger menu → Settings.

Picking a font

In the settings Code font and UI font pickers, choose from bundled fonts together with installed system fonts. Each row is a sample drawn in that font, so you can visually compare Korean glyph widths and how clearly il1Lo0 are distinguished. The code font picker shows monospace only, while the UI font picker shows them all.

App background · panel translucency

The App background · panel translucency group in Settings → Appearance places a background picture inside the app and makes only panel backgrounds translucent, so the picture shows through while text stays sharp. It applies instantly without a restart, and since the app window itself stays opaque it adds almost no GPU load.

  • Background image — Choose image… (PNG, JPG or WebP, up to 20 MB), Default (a dark sky with floating rock islands) or No image.
  • Panel opacity (0–100%) · Dim background (0–70%).
  • Applies to — always used in spatial mode; turn on Also outside spatial mode to use it on the regular split screen too. While you use a see-through window with Window opacity below, it is not applied outside spatial mode.
  • These are the same settings as Background in the spatial mode controls, so changing either updates both. In-app browser pages stay opaque.

Window opacity

The Window opacity slider under Settings → Appearance → Window transparency · rendering makes the whole app window translucent so your desktop shows through. Main surfaces like the Explorer, headers, and editor body fade together, while menus, modals, and palettes stay crisp for readability.

The default is 100% (opaque window). A transparent window greatly increases GPU compositing load, so lowering the slider from an opaque window asks for confirmation and the transparent window takes effect only after restarting the app. Raising it back to 100% offers to restart now; after a restart (or from the next launch) the window is opaque again (less GPU).

Terminal renderer

Choose it under Settings → Appearance → Terminal renderer. DOM (default) uses less GPU; WebGL draws heavy output faster and joins box/block characters (─ │ █, agent TUI borders, etc.) seamlessly between rows, but uses more GPU (you'll be asked to confirm). With DOM, thin gaps may appear between box lines depending on display scaling. The change applies to open terminals immediately.

AI usage

If you use Codex, Claude, Antigravity or xAI (Grok), the status bar shows how much of each service's usage limit you have used. It reads the sign-in of each CLI you already have installed, so there is nothing to sign in to separately, and services you are not signed in to do not appear (if there are none, the whole area is hidden).

Reading the status bar

Each service shows a monochrome icon + percentage used + a small bar. A service with two limits is split into two lines. Hover over it for a tooltip naming the service and what each line is.

ServiceTop lineBottom line
CodexWeekly limit— (Codex currently reports only its weekly limit)
Claude5-hour limitWeekly limit
AntigravityGemini models groupClaude and GPT models group (both are weekly limits)
xAI (Grok)Credits used in the current billing period (shared by Grok chat and Build)—
  • The number is the share used. 59% means you have used 59% of that limit and 41% is left.
  • Bar color shows pace, not usage. If you are using a limit faster than its period is passing, it turns yellow → orange → red (thresholds in the detail popover).
  • A dimmed icon means an earlier value rather than a fresh one — right after the app restarts, or when the last refresh failed.
  • A yellow dot at the icon's top right means the last refresh failed. The reason is shown in the detail popover.
  • — means the value is unknown (still loading, connection failed, or the limit has already reset). It never shows a made-up 0%.

In a narrow window

When the window is too narrow for everything to fit, AI usage collapses one step at a time. It expands again when the window gets wider, and clicking it in any form opens the same detail popover.

  • A — default: icon + percentage + bar.
  • B — number chips: bars are dropped and only numbers remain. Two limits are split with a slash, as in 18/59, and each number takes its pace color.
  • C — single indicator: only ● AI remains. The dot takes the pace color of the limit you are using fastest, and a yellow dot is added if any refresh failed.

Turning it on or off — Settings → Status bar

Change it under the hamburger menu → Settings → Status bar. Changes apply immediately; no restart is needed.

SettingWhat it does
Show in status barTurns AI usage on or off as a whole. On by default. When it is off, nothing is queried and no CLI is run.
Per-service checkboxesChoose which services to show; unchecked services are not queried. Chips: Signed in · No sign-in record · No plan limits (nothing to show, e.g. when you use only an API key) · Not supported on this OS.
Refresh every1, 2, 5 or 10 minutes (2 minutes by default). Refreshes are skipped while the window is hidden or minimized, and run right away when it comes back if the values are stale.
System — CPU · MEM · GPUTurns the gauges at the far right on or off.
  • How it queries — for Claude and xAI, it uses each CLI's sign-in token to contact only that service's servers. For Codex and Antigravity, it briefly runs the installed CLI (codex, agy) to read the values.
  • No tokens are consumed — a usage query is not a conversation, so it does not count against your limits. Sign-in tokens are never stored or sent anywhere else, and Orch term never refreshes them itself.
  • macOS Keychain — Claude's sign-in is read with the system security tool, so a Keychain approval prompt normally does not appear.
  • Linux is not supported yet (the chips show Not supported on this OS).

Messages in the detail popover

When a refresh fails, the reason appears in orange under the service name in the detail popover. An earlier value, if any, stays visible (dimmed), and other services are not affected.

MessageMeaning · what to do
Sign-in expired · run Claude Code once to refreshThe CLI's sign-in has expired. Use that CLI once to renew it, and values return on the next refresh.
Run Grok to refreshThe xAI sign-in expires after a few hours. Run Grok once to renew it.
Rate limited · retrying at 14:32The service's server has paused queries for a while. It retries automatically at that time and, if it keeps getting limited, waits longer each time, up to 30 minutes. The refresh button respects this wait too.
Connection failed · retrying next refreshA network error or timeout. It tries again automatically on the next refresh.
Access denied · check account permissionsThe server refused the usage query for this account.
Response format changed · update Orch termThe service changed its response structure. An Orch term update fixes it.
codex (or agy) executable not foundThere is a sign-in record but the CLI could not be found. Check that the CLI is installed.

Settings dialog

Open it from the hamburger menu → Settings. Move between the General, Appearance, Terminal, Status bar, Agent mirror, AI gateway, Agent orchestration, Backup, and Shortcuts groups via the left nav, and change values in the right panel.

From the Backup tab you can export settings to a file and import them. Import only applies settings the app recognizes, blocking dangerous values from external files.

Reassign keyboard shortcuts

In the settings Shortcuts section, click a row and press the keys you want to reassign it. It works regardless of keyboard layout, and if it clashes with another command or a fixed shortcut it's shown in red and saving is blocked.

Hamburger menu · About

Click the hamburger at the top left of the titlebar to bring up Settings and About. The button on the right cycles the theme dark → midnight → light.

About shows the brand, version, author, and the list of open-source licenses. Licenses are gathered automatically at build time and are collapsed by default — expand them when you need them.
