시작하기 · 다운로드 · 설치

다운로드 · 설치

Windows·macOS용 빌드를 GitHub Release에서 받습니다. 미서명 빌드라 첫 실행 때 OS 경고가 한 번 뜨지만, 아래 안내대로 넘기면 됩니다.

Windows

설치 관리자(orchterm-setup.exe) 또는 MSI(orchterm-x64.msi)를 받아 실행합니다. 두 링크 모두 항상 최신 빌드를 가리킵니다.

orchterm-setup.exe .msi (x64)
  1. 받아서 실행

    둘 중 하나를 내려받아 더블클릭합니다.

  2. SmartScreen 경고 넘기기

    미서명이라 Windows가 "알 수 없는 게시자(Unknown publisher)" 경고를 띄울 수 있습니다. 추가 정보(More info) → 실행(Run anyway)을 누르면 설치가 진행됩니다.

macOS

가장 쉬운 방법은 터미널 한 줄입니다. install.sh가 Apple Silicon 빌드를 받아 설치하고, 격리(quarantine)까지 해제합니다. curl로 받은 파일은 격리 속성이 붙지 않아 "손상되어 열 수 없습니다" 경고를 애초에 피합니다.

$ curl -fsSL https://github.com/zendy00/orch-term-pages/releases/latest/download/install.sh | sh

직접 .dmg로 설치

직접 .dmg를 받아 설치할 수도 있습니다.

Apple Silicon (.dmg)

.dmg를 열어 앱을 /Applications로 옮긴 뒤, 첫 실행 전에 격리 속성을 한 번 벗겨 줍니다.

$ xattr -dr com.apple.quarantine /Applications/orchterm.app

install.sh는 다음 릴리즈부터 제공됩니다.

미서명 안내

현재 빌드는 코드서명·공증(notarization)이 되어 있지 않습니다. 첫 실행 때 OS가 한 번씩 경고를 띄우지만, 위 안내대로 넘기면 정상 동작합니다.

Windows는 SmartScreen "알 수 없는 게시자", macOS는 Gatekeeper 격리(quarantine) 경고입니다 — 모두 위 절차로 한 번만 넘기면 됩니다. 코드서명/공증은 추후 과제입니다.
