대형 기능

이름값 하는 다섯 기둥

Orch term을 단순 터미널이 아니라 멀티에이전트 워크스테이션으로 만드는 핵심 기능들. 각 카드는 상세 사용설명으로 이어집니다.

멀티에이전트 워크스테이션

터미널·에디터·브라우저를 한 창의 분할 패널에. 탭 종류 3종을 자유롭게 배치.

→ 한 창의 구조

에이전트 오케스트레이션

대화 중인 AI가 다른 AI를 워커로 띄워 다중 턴으로 협업. 지휘자/워커 모델.

→ 지휘자 가이드 MCP :9611 · open/send/close

AI 게이트웨이

외부 프로그램이 로컬 API(OpenAI 호환)로 AI를 호출. machine-to-machine 자동화.

→ 게이트웨이 HTTP :9610 · /run · Bearer

SSH · SFTP

native russh 인-탭 접속. 원격 탐색기·SFTP 편집·볼트·포트 포워딩 터널.

→ SSH 가이드

CDP 브라우저 미러

에이전트(chrome-devtools-mcp)의 브라우징을 인앱 패널에 실시간으로 비춤.

→ 미러 가이드
