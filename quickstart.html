빠른 시작

처음 켠 순간부터 5분 안에 한 바퀴 — 첫 터미널, 셸 추가, 패널 분할, 파일 편집, 인앱 브라우저, 그리고 (옵션) 다른 AI를 워커로 부리는 오케스트레이션까지.

5분 안에 한 바퀴

설치는 다운로드 · 설치를 참고하세요. 앱이 떠 있다면 아래 단계를 순서대로 따라가며 핵심 화면을 만져봅니다.

  1. 앱 실행 — 첫 터미널이 자동으로

    앱을 실행하면 별도 조작 없이 첫 터미널 탭이 자동으로 열립니다. 새 터미널은 탐색기의 활성 프로젝트 루트에서 시작합니다.

  2. 새 터미널 · 셸 선택 (＋)

    탭바의 ＋ 또는 패널 우상단 액션으로 새 터미널을 엽니다. 설치된 셸을 자동 감지해 드롭다운에 보여줍니다 — PowerShell · cmd · Git Bash · WSL 등.

  3. 패널 분할 — 화면 나누기

    패널 우상단의 분할 액션으로 화면을 나눕니다 — 아래로, 오른쪽. 각 패널은 독립된 셸이고, Ctrl+Alt+방향키로 인접 패널을 오갑니다.

  4. 파일 더블클릭 → 에디터 탭

    탐색기에서 파일을 더블클릭하면 활성 패널에 에디터 탭으로 열립니다(단일 클릭은 미리보기). 외부 변경 자동 리로드 · 인코딩 표시 · Ctrl+F 찾기를 지원합니다.

  5. 주소 입력 → 인앱 브라우저 탭

    주소창에 URL을 입력하면 인앱 브라우저 탭으로 엽니다. https면 자물쇠가 뜨고, 버튼으로 시스템 브라우저에서 엽니다. 로컬 파일도 바로 봅니다.

  6. (옵션) 오케스트레이션 — 워커 부르기

    설정에서 오케스트레이션을 켜면(기본 꺼짐), 지휘자(claude) 탭에서 자연어로 다른 AI(codex · agy · claude)를 워커로 띄워 다중 턴으로 협업시킬 수 있습니다.

    켜려면 재시작이 필요하고(127.0.0.1 전용), 앱 안 에이전트 협업이 필요 없으면 이 단계는 건너뛰어도 됩니다.

다음엔 어디로

한 바퀴를 돌았다면, 각 기능의 디테일은 아래에서 이어집니다.

터미널

복사·붙여넣기, 줄바꿈(Shift/Ctrl+Enter), 스크롤백, 셸 종료 자동 닫기.

탭 · 패널

가로/세로 분할, 패널 최대화(Shift+Esc), 탭 색·드래그, 패널 네비게이션.

코드 에디터

외부 변경 자동 리로드, 인코딩 표시, 마크다운 스타일, 테마 추종.

오케스트레이션

다른 AI를 워커로 띄워 다중 턴으로 협업.

알아두면 좋은 단축키
