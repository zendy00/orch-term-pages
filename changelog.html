변경 이력 (Changelog)

버전별 새 기능·수정 내역입니다. 자동 업데이트(v0.1.23부터)가 켜져 있어, 새 버전이 올라오면 타이틀바 배너로 알려주고 한 번에 받습니다. 각 릴리즈 노트는 Conventional Commits에서 자동 생성됩니다.

표기 — feat 새 기능 · fix 버그 수정 · perf 성능. 날짜는 태그 생성일 기준입니다.

0.8.0 — 에이전트 세션 복원 · 탭 이름=대화 이름 · 인앱 브라우저 멎음 수정

v0.8.02026-09-03최신
  • feat재시작해도 AI 대화가 그대로 — 각 터미널 탭에서 돌던 Claude Code·Codex·Antigravity·Grok·opencode·Hermes 대화가 자동으로 다시 열립니다. 셸에 직접 친 것과 별칭(cl)도 알아내고, 강제 종료·크래시 뒤에도 복원하며, 대화를 갈아탔으면 갈아탄 그 대화로 돌아옵니다(설정 → 터미널에서 끌 수 있음)
  • feat탭에 붙인 이름이 곧 대화 이름 — 터미널 탭 이름을 바꾸면 그 탭의 AI 대화가 세션 목록에서도 같은 이름으로 보입니다. 순서는 상관없고(이름을 먼저 붙이고 나중에 실행해도 붙습니다), 목록에서 이름을 바꾸면 탭 이름도 따라갑니다
  • feat세션 목록이 여섯 CLI를 모두 지원 — 기존 Claude·Codex·Antigravity에 Grok·opencode·Hermes 추가(Ctrl+Shift+S)
  • feat멈춘 브라우저 탭 되살리기를 명령 팔레트에 추가 — 탭을 닫지 않고 보던 주소 그대로 다시 엽니다(Ctrl+Shift+P)
  • fix인앱 브라우저를 쓰다 앱이 느려지거나 멎던 문제 수정 — 죽은 브라우저 화면에 구분선 드래그·창 크기 변경마다 초당 수십~수백 건씩 헛명령을 보내던 것을 상태가 바뀔 때만 보내도록(실측 하루 1412건)
  • fix브라우저 탭이 설명 없이 백지로 남던 문제 수정 — 사유를 탭 안에 표시하고 주소창 재입력으로 다시 엽니다. 같은 주소 재열기도 동작
  • fix재시작 후 일부 터미널 탭이 빈 화면으로 남던 문제 수정 — 복원 도중 뒤 탭이 앞 탭의 셸을 가로채던 것(탭 11개에 셸 9개)
  • fixCodex 대화 이어가기 실패 수정 — No saved session found with ID로 재개가 안 되던 문제
  • fixAI 대화 안에서 앱을 실행하면 새 터미널이 그 대화를 물려받던 문제 수정 — 복원해야 할 탭이 통째로 누락되곤 했습니다
