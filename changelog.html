릴리즈 · 변경 이력

변경 이력 (Changelog)

버전별 새 기능·수정 내역입니다. 자동 업데이트(v0.1.23부터)가 켜져 있어, 새 버전이 올라오면 타이틀바 배너로 알려주고 한 번에 받습니다. 각 릴리즈 노트는 Conventional Commits에서 자동 생성됩니다.

표기 — feat 새 기능 · fix 버그 수정 · perf 성능. 날짜는 태그 생성일 기준입니다.

0.6.0 — 노트 · 다이어그램 · AI 노트 공유

v0.6.02026-07-14최신
  • feat메모(노트) 패널 — 타이틀바 메모 버튼(Ctrl+Shift+N)으로 여는 플로팅 Post-it. 탭·색상·고정·이름 변경, 마크다운 미리보기, 파일 저장, 텍스트 노트는 메인 패널 탭으로 확장
  • feat그림 노트 — Excalidraw 캔버스 자유 드로잉(오프라인 동작), 격자 토글, PNG/SVG/PDF/클립보드 내보내기
  • feat시퀀스 다이어그램 노트 — 드래그로 그리는 UML 시퀀스 편집기(도구 팔레트·활성화 막대·loop/alt/opt/par 프레임·자유 배치·손 패닝·도구 단축키), Mermaid(.mmd)/SVG/PNG/PDF 내보내기
  • feat순서도 노트 — 캔버스에서 드래그로 그리면 Mermaid 코드가 되고, Mermaid를 불러오면 편집 가능한 도형이 되는 양방향 편집기(도형 5종·연결선 4종·방향 전환·자동 정렬·밝은/어두운 배경)
  • featAI 노트 공유 — 앱 안 AI 에이전트가 노트를 직접 생성·조회·수정(orchterm-notes MCP, 기본 켜짐). 시퀀스·순서도는 Mermaid로 읽고 써서 AI와 왕복 편집 가능
  • feat기본 코드 폰트로 Jetendard(JetBrains Mono + Pretendard) 내장 — 폰트가 설치되지 않은 PC에서도 동일하게 표시
  • fix설정에서 고른 코드 폰트가 코드 편집기·메모장에 적용되지 않던 문제 수정 — 터미널에만 적용되고 있었음
  • fix그림 노트를 열어둔 채 AI가 수정하면 캔버스에 즉시 반영 — 이전엔 열려 있던 옛 그림이 AI 수정을 되덮을 수 있었음
  • fix그림·시퀀스 노트 배경이 창 투명도 설정을 따라가도록 수정
