자동 업데이트

새 버전이 나오면 타이틀바에 액센트 pill로 알립니다. 클릭하면 다운로드 → 재시작으로 설치합니다. 앱을 켤 때 한 번 자동으로, 그리고 정보(About) 창에서 직접 확인할 수 있습니다.

새 버전 알림 (타이틀바 pill)

새 버전이 감지되면 타이틀바 오른쪽에 액센트 pill이 나타납니다. 클릭하면 설치로 진행하고, 닫기를 누르면 그 알림만 숨깁니다.

pill 라벨은 진행 상황에 따라 바뀝니다.

  • 새 버전 — 클릭하면 설치를 시작합니다.
  • 다운로드 중 — 진행률을 표시합니다.
  • 설치 준비됨 — 재시작하면 새 버전으로 바뀝니다.
  • 실패 — 클릭하면 다시 시도합니다.

다운로드 · 재시작 설치

pill을 클릭하면 설치 전 확인 창이 뜹니다. 동의하면 새 버전을 내려받아 설치하고 앱을 재시작합니다. 취소하면 아무것도 받지 않고 알림 상태로 돌아갑니다.

설치하면 앱이 재시작됩니다. 진행 중인 작업을 먼저 저장하세요.

부팅 체크 · About 수동 확인

업데이트 확인은 두 갈래입니다 — 앱이 뜰 때 자동으로 한 번, 그리고 정보(About) 창의 Check for Updates 버튼으로 직접. 둘은 결과를 공유하므로 About에서 확인한 새 버전이 타이틀바 pill에도 그대로 나타납니다.

서명 · 릴리즈 노트

업데이트는 서명으로 검증되어 변조된 빌드가 설치되지 않습니다. 릴리즈 노트(변경 사항)는 커밋에서 자동으로 만들어져 GitHub 릴리즈와 인앱 알림에 함께 표시됩니다 — 손으로 쓰지 않습니다.

DEV 미지원 · 플랫폼 제약

자동 업데이트는 릴리즈 빌드 전용입니다. 개발(dev) 빌드는 부팅 자동 체크가 없고, Check for Updates를 눌러도 미지원 안내만 뜹니다.

설치 파일은 Windows는 설치 관리자(.exe · MSI), macOS는 .dmg로 배포됩니다.
